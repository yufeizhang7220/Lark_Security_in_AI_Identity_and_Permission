## 项目简介

身份注册模块是IAM系统的核心组件之一，负责管理用户、访客和机器Agent的身份注册与验证。

**核心功能：**
- 用户/访客注册
- 机器Agent注册
- 身份校验
- 审计日志记录

## API接口详解

### 1. 用户/访客注册

**接口地址**：`POST /IAMsystem/identity/register/user`

**请求参数**：
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| Agent_name | string | 是 | 用户名称，全局唯一 |
| subtype | string | 是 | 身份类型：user/visitor |
| scope | object | 是 | 权限集合 |
| ip | string | 否 | 注册IP地址，默认127.0.0.1 |

**请求示例**：
```json
{
  "Agent_name": "张三",
  "subtype": "user",
  "scope": {"doc": ["read", "write"], "online": ["web_search"]},
  "ip": "192.168.1.100"
}
```

**响应示例**：
```json
{
  "code": 201,
  "message": "success",
  "data": {
    "Agent_name": "张三",
    "subtype": "user",
    "scope": {"doc": ["read", "write"], "online": ["web_search"]},
    "agent_id": "user_1777000000_abc123",
    "agent_secret": "32位随机密钥",
    "registered_at": 1777000000
  }
}
```

### 2. 机器Agent注册

**接口地址**：`POST /IAMsystem/identity/register/bot`

**请求参数**：
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| Bot_name | string | 是 | Bot名称，全局唯一 |
| Bot_id | string | 否 | 自定义BotID，系统自动生成 |
| scope | object | 是 | Bot自身权限集合 |
| sub_scope | object | 否 | 不同身份的权限映射 |
| api_endpoint | string | 否 | Bot服务地址 |
| ip | string | 否 | 注册IP地址 |

**请求示例**：
```json
{
  "Bot_name": "外部检索Agent",
  "scope": {"online": ["web_search"], "iam": ["verify_token"]},
  "sub_scope": {
    "user": {"online": ["web_search"]},
    "visitor": {"online": ["web_search"]}
  },
  "api_endpoint": "http://localhost:8002/api",
  "ip": "127.0.0.1"
}
```

### 3. 身份校验

**接口地址**：`POST /IAMsystem/identity/verify`

**请求参数**：
```json
{
  "agent_id": "user_1777000000_abc123",
  "agent_secret": "用户密钥"
}
```

**响应示例**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "valid": true,
    "scope": {"doc": ["read", "write"]}
  }
}
```

### 4. 健康检查

**接口地址**：`GET /IAMsystem/health`

**响应示例**：
```json
{
  "code": 200,
  "message": "success",
  "data": {"status": "healthy"}
}
```

## 日志功能

### 日志文件位置
```
Logs/Identity_Registration_Log/registration_YYYYMMDD.log
```

### 日志格式（JSON格式，一行一条）
```json
{
  "log_id": "uuid",
  "timestamp": 1777000000000,
  "agent_id": "user_xxx",
  "agent_name": "用户名",
  "ip": "192.168.1.100",
  "operation": "register",
  "status": "success",
  "detail": {"subtype": "user", "scope": {...}, "agent_secret": "****"}
}
```

### 查看日志
```bash
# 查看今天的日志
Get-Content "Logs/Identity_Registration_Log/registration_$(Get-Date -Format 'yyyyMMdd').log"

# 实时跟踪
Get-Content "Logs/Identity_Registration_Log/registration_$(Get-Date -Format 'yyyyMMdd').log" -Wait
```

## 使用示例

### Python调用示例
```python
import requests

BASE_URL = "http://localhost:9000/IAMsystem"

# 用户注册
response = requests.post(f"{BASE_URL}/identity/register/user", json={
    "Agent_name": "测试用户",
    "subtype": "user",
    "scope": {"doc": ["read"]},
    "ip": "127.0.0.1"
})
print(response.json())

# 身份校验
response = requests.post(f"{BASE_URL}/identity/verify", json={
    "agent_id": "user_xxx",
    "agent_secret": "用户密钥"
})
print(response.json())
```

### curl调用示例
```bash
curl -X POST http://localhost:9000/IAMsystem/identity/register/user \
  -H "Content-Type: application/json" \
  -d '{"Agent_name":"测试","subtype":"user","scope":{"doc":["read"]}}'
```

## 注意事项

1. **Agent_name唯一性**：用户名和Bot名称全局唯一，重复注册会被拒绝
2. **密钥安全**：agent_secret仅在注册时返回一次，请妥善保存
3. **bcrypt加密**：密钥采用bcrypt算法加密存储，不可逆
4. **权限格式**：scope必须是JSON对象，键为资源类型，值为操作列表
5. **日志保留**：日志按日期分割，一天一个文件
6. **审计要求**：所有操作都会被记录到审计日志
