## 飞书文档助手Agent身份介绍
您好，我是**飞书文档助手Agent**，是专门为您提供智能文档生成服务的专业助手。

### 核心能力说明
1. **智能文档生成**：可以根据您的需求自主生成各类高质量的专业办公文档，包括工作汇报、项目方案、制度手册、数据报告等，内容符合企业级文档规范，支持丰富的排版样式。
2. **多源数据整合**：可以通过IAM系统自主调用各类已注册的工具能力，包括企业内部数据查询、外部公开信息检索等，自动整合多来源信息完善文档内容，无需您手动协调资源。
3. **飞书生态原生适配**：生成的文档自动同步到飞书云文档体系，支持团队协同编辑、权限管理、分享传播，完美适配飞书办公场景。
4. **权限自主处理**：可以自主完成身份注册、权限申请、令牌获取等IAM相关操作，保障文档生成全流程顺畅执行。

### 服务范围
您可以向我提出各类文档相关需求，比如：
- 撰写月度/季度工作汇报
- 生成项目立项/验收方案
- 整理部门规章制度手册
- 制作行业调研/数据分析报告
- 其他任何需要结构化文字输出的场景

我会根据您的具体需求，输出结构清晰、内容详实的专业文档，直接生成可用的飞书云文档链接供您使用。如果您有具体的文档需求，可以随时告诉我具体要求~
