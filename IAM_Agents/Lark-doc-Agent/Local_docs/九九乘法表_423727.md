<h1>3 使用指南</h1>
<ul>
  <li><strong>背诵技巧</strong>：可按行逐行记忆，结合运算规律降低难度：2的乘法结果均为偶数，5的乘法结果末尾为0或5，9的乘法结果个位与十位数字之和为9</li>
  <li><strong>训练方法</strong>：可随机抽取乘法公式进行口算测试，每日练习10-15分钟，1-2周即可熟练掌握全表内容</li>
  <li><strong>拓展应用</strong>：熟练掌握后可延伸学习两位数乘法、除法运算，夯实数学计算基础</li>
</ul>
