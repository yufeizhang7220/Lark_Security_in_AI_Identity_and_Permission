## 二、本次申请执行说明
本次执行AccessToken申请操作时触发系统异常，具体调用情况如下：
1. 首次调用`iam_list_tools`查询可用工具：返回错误提示「缺少有效的AccessToken，请先调用iam_apply_access_token申请令牌」
2. 调用`iam_register_agent`完成Agent注册：返回404 Not Found错误，服务访问异常
3. 调用`iam_apply_access_token`提交令牌申请：返回状态码602，令牌申请失败

## 三、AccessToken标准申请流程（后续操作参考）
### 1. 前置准备：完成Agent注册
- 调用接口：`iam_register_agent`
- 固定配置：AgentID=Lark-doc-Agent，身份类型=bot，默认注册IP=127.0.0.1
- 必填参数：`scope`（权限范围，示例：`{"doc": ["all"], "iam": ["all"]}`）
- 注册成功后获取专属`AgentSecret`，作为后续令牌申请的必备凭证

### 2. 正式申请AccessToken
- 调用接口：`iam_apply_access_token`
- 必备参数：
  - `AgentSecret`：注册阶段获得的专属密钥
  - `scope`：需要申请的权限范围，格式为`{"数据类型": ["操作列表"]}`
- 可选配置：有效期`time`，最大支持86400秒（24小时），默认3600秒

### 3. 令牌使用规范
- 申请成功后返回的AccessToken可用于所有IAM相关接口的身份校验
- 令牌在有效期内可重复使用，过期前可提前提交续期申请

## 四、后续操作建议

3. 使用正确的AgentSecret参数重新提交AccessToken申请
4. 申请成功后将返回的AccessToken值补充到本文档对应位置留存
