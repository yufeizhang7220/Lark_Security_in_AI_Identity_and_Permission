在 E:\CODE\AI\_Lark\Lark\_Security\_in\_AI\_Identity\_and\_Permission\IAM\_Agents\Lark-doc-Agent 目录下创建一个（飞书文档助手agent/Lark-doc-Agent），要求使用火山引擎的自定义模型，模型ID和api\_key由我后期决定

## agent工作内容

这个agent的主要内容是根据用户输入，负责理解用户需求，创建飞书报告

agent需要能理解用户的输入，自己思考，合理的调度工具，最后创建文档

## agent可调用工具

agent可以调用调用 IAM\_Agents\Lark-doc-Agent\SKILLS.py 里的工具



## API相关

### 主要功能API：

API: localhost:9100/Lark-doc-Agent

其中请求json文件是

```JSON
{
    "title":"文档的标题",
    "user_input":"用户输入的提示词"
}
```

响应的json文件未作定义，可自行决定

### 网页前端地址

url: localhost:9100/Lark-doc-Agent/Web

是使用该agent的前端页面

## 前端相关

### 前端代码的位置

前端的html css js 页面应该写在 IAM\_Agents\Lark-doc-Agent\WebPages 下

### 前端网页的内容

主要有两个区 左 和 右 ，大小比例 1：3

左边是用户输入

右边是结果展示

## 日志写入

将日志写入IAM\_Agents\Lark-doc-Agent\Logs 目录下

### 用户输入日志

这里的工具指代 请求json的 data online

格式 : 每次任务记录一条

\[时间] \[文档标题] \[用户输入] \[用户要求使用的工具] \[最后成功使用的工具] \[创建结果] \[创建文档在本地的位置] \[创建文档的url]

### skill使用日志

格式 ：每次任务记录一条

\[时间] \[一次任务中使用的skill列表，要求有先后顺序]

使用 volcenginesdkarkruntime 库接入模型，其中api\_key 和 model 由配置文件 IAM\_Agents\Lark-doc-Agent\config.py 提供
